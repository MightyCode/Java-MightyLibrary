# Gros point actuel — Tests de non-régression

**Ce fichier ne contient que ce qui reste à faire, jamais l'historique.** Quand un objectif est atteint (même en partie) : supprimer sa ligne, ou la réécrire pour ne garder que le reste. Aucun « fait », « déjà », « aujourd'hui fait X » : l'état actuel est décrit dans `architecture.md`, l'historique est dans git. Fichier vide → **discuter** avec l'utilisateur du point en tête de `later.md`, puis l'écrire ici (format et cycle de vie : `later.md`, « Écrire `current.md` »). Propositions **à valider avec l'utilisateur avant d'appliquer** ; changements cassants maintenant, avant toute version publiée. Chaque objectif passe par `/planification-ml` avant son implémentation. (U) = le plus urgent.

Philosophie de `decisions.md` : usage courant facile (niveau Processing), réimplémentation (presque) complète possible par héritage + injection. Prérequis de la bibliothèque réutilisable, du modding, du thème et des langues, de Lua et de la physique injectable : chaque commit écrit sans elle ajoute du code à reprendre.

Filet avant les gros chantiers suivants (physique 2D et unité du monde, entités et Lua, effets 2D), qui toucheront caméras, renderers et scènes : aujourd'hui une scène cassée, une fuite ou un rendu changé ne se voient qu'à la main (`scenario.py`, `leakcheck`). Les scénarios s'écrivent en JUnit avec le kit (`SceneRunner`, entrées simulées, fuites vérifiées autour de chaque test par `MightySceneExtension`), plus par `tools/mighty.py`. **Critère de fin** : toute scène de `DemoScenes` est chargée par `mvn test` et en CI, une fuite, une scène cassée ou un rendu changé dans une scène de référence font échouer le build, et chaque bug connu corrigé a un test qui le reproduit.

- **Test de fumée de toutes les scènes de la démo** : 38 scènes dans `DemoScenes.ALL` au 2026-11-26, 4 avec un test GL (`Scene2DTest`, `VectorShapes2DTest`, `BatchStress2DGLTest`, `TileMapBatchGLTest`) ; `leakcheck` (allers-retours de scènes) n'existe que dans `scenario.py`, hors CI.
  - Cible : un test GL paramétré sur `DemoScenes.ALL` : chargement, quelques frames, aucune erreur GL ni problème dans le journal, aller-retour par une autre scène sans fuite (objets GL, sources de son). Les scènes 3D (`Scene3D`, `Scene3DBis`, `Game3D2D`, `TerrainGeneration3D`) comprises ; une scène qui demande le paquet de démonstration (`tools/demo_assets.py`, hors de git) est ignorée (`assume`) quand il manque, ou le CI le télécharge.
